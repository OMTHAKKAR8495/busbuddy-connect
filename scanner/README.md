# 🔍 GSFCU Conductor Bus Pass QR Scanner

This directory contains the dedicated **Conductor Gate Scanner Terminal** for verifying GSFC University student bus entry passes.

---

## 🛠️ Features

1. **Animated Viewfinder & Laser Scanner**:
   - Visual scanner line indicating live camera / QR scanning activity.
2. **Instant Demo Evaluation Presets**:
   - Pre-loaded with student evaluation profiles (e.g. *Om Thakkar*, *Alex Sharma*, and expired pass demo) for quick 1-click verification during presentations.
3. **Student Identity Verification Card**:
   - Displays Student Photo / Avatar, Full Name, Roll Number, Department, Phone, Route Assignment, Validity Dates, and Fee Payment Status.
4. **Verification Audio Beep**:
   - Synthesizes audio feedback chime (high-frequency beep for valid, low buzz for invalid/expired).

---

## 🚀 How to Access

- **In Main App Console**: Click **`🔍 QR Scanner`** in the top Faculty Evaluation Bar at **[http://localhost:3000/app](http://localhost:3000/app)**.
- **Standalone HTML**: Open `scanner/index.html` directly in any web browser.
