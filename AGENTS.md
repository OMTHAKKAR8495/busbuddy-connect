# GSFCU Transit Project Guidelines

This repository contains the GSFCU Transit live bus tracking and digital bus pass application built with React, TanStack Start, Tailwind CSS, and Supabase.

Security rules:
- Never fetch or otherwise request a user-supplied URL from server code. Store uploaded files by validated storage path and serve them with short-lived signed URLs.
- Never log passwords, access tokens, phone numbers, full roll numbers, QR payloads, or database error details containing user data.
- Do not add demo identities, mock passes, seeded attendance, client-side role overrides, or authentication bypasses to production code.
